## Overview

SafeZone AI is a proposed computer-vision system for identifying people entering designated hazardous zones in industrial environments.

The goal is to help factory safety officers identify potential safety incidents faster than manual observation alone. The pipeline is intended to process a video stream, detect people, check whether detections overlap a configured restricted zone, and generate actionable incident metadata.

This repository is intended for the CraftifAI PipeGen Buildathon submission. The actual PipeGen export, test evidence, and measured performance must be added after implementation.

## Problem Statement

Factory safety officers may need to monitor multiple camera feeds to identify people entering restricted or dangerous areas. Continuous manual observation can make it difficult to notice every event promptly.

SafeZone AI aims to automate part of this monitoring process by identifying potential hazard-zone entry events and making them available for review.

## Proposed Solution

The planned pipeline consists of:

1. **Video input:** Read a supported sample video, recorded workplace footage, or compatible live camera stream.
2. **Person detection:** Run a suitable computer-vision model on incoming frames.
3. **Zone evaluation:** Compare detected person locations with a configurable restricted-zone region.
4. **Event generation:** Generate an event when a person is detected inside the configured region.
5. **Actionable output:** Publish supported event metadata or display an alert for a safety officer to review.

The implemented stages and output types will be documented after testing.

## Limitations

- The system has not yet been validated in a real factory environment.
- Lighting, occlusion, camera placement, and crowded scenes may affect detection.
- Hazard-zone configuration requires appropriate calibration for the camera view.
- Detection alone does not establish that an incident occurred.
- The system is intended to assist safety personnel, not replace established safety procedures.
